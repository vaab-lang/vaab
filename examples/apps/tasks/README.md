# Task API (multi-file casts)

Reference layout for a Vaab HTTP app: **one cast per route**, shared libs in local riffs.

```
examples/apps/tasks/
  main.vaab              serve block + need imports
  riff                   app manifest
  needed.lock            generated by vaab gather
  lib/
    errors/              ApiError, AuthError, …
    models/              User, Task, NewTask, …
    database/            cast Database
    auth/                cast Auth
    routes/
      health/            cast HealthRoute
      me/                cast MeRoute
      tasks/             cast TasksRoute
      quote/             cast QuoteRoute
```

## Run

```sh
cd examples/apps/tasks
cargo run -p vaab-cli --bin vaab -- gather
AUTH_SECRET=dev cargo run -p vaab-cli --bin vaab -- serve main.vaab
```

Routes pass `request.who` (and `body`) into cast methods — auth lives in the route body, not inside unrelated modules.

The single-file CI example is `examples/15_first_class_app.vaab`.
